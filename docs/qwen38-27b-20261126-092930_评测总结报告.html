六、结论与建议

  • 稳定性：1→8 并发全程 0 错误、100% 成功率，稳定最大并发为 8；机器侧热控 Nominal，GPU 高频运行但未出现明显降频。
  • 吞吐：输出 token 吞吐从并发 1 的 4.78 tok/s 提升到并发 8 的 14.79 tok/s，约 3.1 倍；但请求吞吐与 TTFT P95 同步劣化，并发 8 的 TTFT P95 达 77.2 s，E2E P95 达 129.0 s。
  • 准确率：含截断口径下，并发 4 最低（65.9%），主要因该档 length 截断最多（66 个，GPQA 31/37）。排除截断后各档均在 94%–96% 左右。
  • 输出长度约束：max_output_tokens=2048 导致 226/882 样本截断，且全部判错。对 GPQA、MMLU-Pro、MATH500、MMLU 等需要长 chain-of-thought 的任务影响尤其大。
  • 建议：正式质量评估建议将 max_output_tokens 提高（例如 4096/8192）或增加“截断样本单独统计”，否则准确率不能反映模型真实能力；性能对比建议采用统一输出上限并报告 TTFT/E2E P95 与 median。
