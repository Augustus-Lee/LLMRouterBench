## 解读

- `GPU active residency` 接近 100% 只说明 GPU 一直在工作。
- 必须结合 power/freq：如果 usage 高但 power 明显低于上限，通常代表访存/带宽瓶颈或低 ALU 占用，不能宣称“算力满载”。
- 如果 usage 与 power 同时接近上限，才是接近计算饱和。
